# Codex Session Hub

一个本地优先的 Codex 多对话任务记忆与知识沉淀工具。

它帮助你在多个 Codex 对话之间保存：

- 当前任务进度
- 已确认的决策
- 未解决问题
- 可复用的知识卡片
- 可直接交给下一次对话的交接语

## 为什么做它

当同时进行多个项目时，重要信息经常散落在不同对话中：

- 不清楚某个任务做到哪一步；
- 忘记之前已经做过哪些决定；
- 新对话无法快速恢复上下文；
- 有价值的经验没有沉淀到自己的知识库。

Codex Session Hub 不读取所有历史聊天，也不后台监听窗口，而是在用户主动触发时，将当前对话整理为结构化的任务记忆或知识卡片。

## 核心特点

- 本地优先，不依赖云端数据库；
- 用户主动触发，不后台监听对话；
- 支持任务同步、交接语生成和知识卡片提取；
- 支持与 Obsidian 本地知识库配合使用；
- 使用 Markdown 保存内容，方便阅读、迁移和版本管理；
- 适合作为 Codex Skill 或 Plugin 使用。

## 当前版本

`v0.1.0`

当前版本重点支持：

- 同步当前任务；
- 查看任务状态；
- 生成新对话交接语；
- 提取可复用知识；
- 将知识卡片保存到 Obsidian。
