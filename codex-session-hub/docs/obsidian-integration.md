# Obsidian Integration

Codex Session Hub treats Obsidian as the durable knowledge layer.

Default output:

```text
~/Documents/Obsidian Vault/40-整理产出/Codex知识卡片
```

Recommended extraction rules:

- Extract reusable knowledge, not full chat logs.
- One card per durable idea.
- Include source session and date.
- Do not store secrets, tokens, cookies, API keys, passwords, or private raw transcripts.
- Update an existing card when the topic clearly matches.

Suggested Obsidian folders:

```text
00-收件箱/Codex待整理
20-项目资料/Codex Session Hub
40-整理产出/Codex知识卡片
```
