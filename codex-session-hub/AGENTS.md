# Codex Session Hub 工作规则

当用户提到以下意图时，使用 `skills/session-hub`：

- 同步当前对话 / 更新当前任务；
- 生成交接语 / 上下文接力；
- 继续某个历史任务；
- 查找历史任务、历史问题、历史决策；
- 提取当前对话中的知识到 Obsidian；
- 列出未解决问题或进行中任务。

默认记忆库：`~/Documents/Codex/session-hub`。
默认 Obsidian 知识目录：`~/Documents/Obsidian Vault/40-整理产出/Codex知识卡片`。

不要保存 access token、refresh token、cookie、API key、密码、身份证件、私密聊天原文。
优先保存压缩后的任务状态、关键决策、未解决问题和可复用知识。
